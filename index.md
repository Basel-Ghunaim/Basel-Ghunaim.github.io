## Background
This project focuses on designing and developing a robotic arm capable of picking and placing different types of objects such as a ball, egg, screw, bolt, and CD. The system combines mechanical gripping with vacuum suction to improve versatility and reliability.

The robotic system integrates both hardware and software components, including stepper motor actuation, sensor-based positioning, and a hybrid end effector. In addition, the system is designed to incorporate a camera-based vision module for object detection and identification.

The architecture includes the use of a Raspberry Pi for high-level processing tasks such as vision and AI-based decision making, and an Arduino (Atmega microcontroller) for low-level control of motors, sensors, and actuators. This separation allows efficient real-time control while enabling more advanced processing capabilities.

The project aims to demonstrate a complete mechatronic system that integrates mechanical design, electronics, control systems, and intelligent decision-making.

## Results
The project investigates stepper motor positioning using step counting and homing, evaluates encoder feedback as an optional enhancement, and develops a hybrid end-effector combining mechanical gripping and vacuum suction. Initial design decisions and system architecture have been successfully established.
